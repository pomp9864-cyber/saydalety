# صيدليتي | Saydalety

واجهة أولية لمنصة صحية عربية موجهة للمستخدم المصري.

## الحالة الحالية
هذا المستودع يبدأ بهيكل الموقع والواجهة التعريفية. لا توجد حتى الآن قاعدة بيانات أدوية موثقة أو خدمات ذكاء اصطناعي أو أسعار مباشرة أو نشر عام متصل.

## التشغيل
افتح `index.html` في المتصفح.

## مبادئ المشروع
- واجهة عربية RTL ومتجاوبة.
- معلومات دوائية لا تُعرض باعتبارها وصفة أو تشخيصًا.
- يلزم توثيق مصادر البيانات ومراجعة المحتوى طبيًا قبل الاستخدام العام.

## التطوير القادم
1. استكمال الواجهة المعتمدة وإضافة الأصول البصرية.
2. إعداد قاعدة بيانات موثوقة للأدوية المصرية.
3. بناء البحث والتصفية.
4. إضافة خدمات آمنة بعد مراجعة المتطلبات الطبية والخصوصية.
