# صيدليتي | Saydalety

منصة صحية عربية RTL موجهة للجمهور المصري والطلاب والصيادلة. تعمل الواجهة كصفحات ثابتة يمكن فتحها محليًا أو استضافتها لاحقًا على خدمة صفحات ثابتة.

## الأقسام الموجودة
- الصفحة الرئيسية والبحث في فهرس أدوية طرف ثالث.
- بحث مساعد من صورة العبوة عبر OCR داخل المتصفح (استخراج نص فقط؛ يجب مراجعة النص والنتيجة يدويًا).
- دليل الأعراض والأمراض بمعلومات تثقيفية وعلامات تستدعي التقييم.
- الإسعافات الأولية.
- مساعد توعوي محدود قائم على قواعد ثابتة، وليس نموذج ذكاء اصطناعي متصلًا.
- مكتبة طبية تعليمية تمهيدية.
- نصائح صحية عامة.
- دليل صيدليات مرتبط بكتالوج السجلات التي تم التحقق منها.

## بيانات الأدوية
مصدر البحث الحالي خدمة طرف ثالث مرتبطة بمشروع Egyptian Drug Database. لا يمثل ذلك سجلًا رسميًا لهيئة الدواء المصرية، ولا يضمن الشمول أو الدقة أو حداثة الأسعار أو استمرارية الخدمة. لا تُعرض نتائج المصدر باعتبارها توصية علاجية. يجب مطابقة المنتج مع العبوة والنشرة والتحقق من السعر لدى الصيدلية.

كتالوج `data/medicines/catalog.json` مخصص للسجلات التي تمر بمراجعة مستقلة. لا تُضاف بيانات أو أسعار أو جرعات بالتخمين. راجع `data/FULL_CATALOGUE_PLAN.md` و`data/CONTRIBUTING.md`.

## دليل الصيدليات
يقرأ `pharmacies.html` من `data/pharmacies/catalog.json` ويعرض السجلات ذات الحالة `verified` فقط. الكتالوج يبدأ فارغًا عمدًا حتى تتوفر بيانات مشروعة ومؤكدة.

## الخصوصية
- لا توجد حسابات أو تسجيل دخول.
- لا تحفظ صفحات المساعد والنصائح إجابات المستخدم في قاعدة بيانات.
- قراءة النص من صورة العبوة تتم داخل المتصفح باستخدام Tesseract.js عند الحاجة؛ لا تُرفع الصورة إلى خادم OCR من هذا المشروع. النص الذي يختاره المستخدم للبحث يُرسل إلى واجهة البحث الخارجية.
- تجنب إدخال البيانات الشخصية أو رفع صور تحتوي على بيانات تعريفية.

## التشغيل والاختبار
افتح `index.html` في متصفح حديث مع اتصال بالإنترنت للخطوط وواجهة البحث ومكتبة OCR الخارجية. بعض الميزات لا تعمل عند فتح الملفات محليًا بسبب قيود المتصفح؛ يفضل تشغيلها من خادم صفحات ثابتة بعد الاختبار.

## الحالة والحدود
هذا إصدار تجريبي أولي (Beta) مخصص للتوعية والاختبار، وليس خدمة طبية معتمدة. لم يتم بعد ربط نموذج ذكاء اصطناعي حقيقي، ولا يوجد سجل أدوية مصري شامل وموثق داخل المستودع، ولا يوجد دليل صيدليات معتمد حتى الآن. صفحات التوعية تحتاج مراجعة مختصين قبل اعتمادها كمرجع سريري أو إطلاقها على نطاق واسع.

## المساهمة
اتبع `data/CONTRIBUTING.md`. السجلات المعلقة لا تُنشر للمستخدمين، وكل معلومة طبية أو سعرية يجب أن تحمل مصدرًا وتاريخ تحقق ومراجعة مناسبة.

## النشر التجريبي عبر GitHub Pages
تم تجهيز سير عمل GitHub Actions في `.github/workflows/pages.yml`. لتفعيل أول نشر:
1. افتح المستودع ثم **Settings → Pages**.
2. في **Build and deployment** اختر **Source: GitHub Actions**.
3. افتح تبويب **Actions**، واختر **Publish Saydalety to GitHub Pages** ثم **Run workflow** على فرع `main` إذا لم يبدأ تلقائيًا.
4. بعد نجاح المهمة، افتح رابط الموقع الذي يظهر في تبويب Pages أو في نتيجة النشر.

كل تحديث جديد على فرع `main` سيبدأ نشرًا تلقائيًا. لا تشارك أي مفاتيح أو كلمات مرور في المحادثة.
