نوضح هنا مصدر كل مجموعة بيانات وما يمكن وما لا يمكن استنتاجه منها.

هيئة الدواء المصرية (EDA)

هي المرجع التنظيمي الرسمي للأدوية في مصر. يمكن زيارة الموقع الرسمي للهيئة. لم نتحقق بعد من وجود سجل عام شامل أو واجهة API/ملف تنزيل متاح لإعادة الاستخدام؛ لذلك لا نزعم أن البحث الحالي متصل مباشرة بقاعدة الهيئة.

Egyptian Drug Database — eg-drugs

ينشر المستودع المتاح على GitHub قاعدة بيانات مجتمعية، ويذكر مطورها أنها تضم أكثر من 27,617 سجلًا وتتوفر بصيغ CSV وJSON وSQLite وSQL، مع API للبحث.

البيانات معلن عنها بترخيص CC BY 4.0. الإسناد: Egyptian Drug Database (eg-drugs) by Mahmoud Mohamed — المصدر.

تستخدم صفحة البحث API المعلن عنها: https://eg-drugs-api.mahmoudfalous.workers.dev/. هذا لا يعني أن كل سجل قد تم تدقيقه طبيًا أو تنظيميًا.

ما الذي لا نضمنه؟

  • اكتمال جميع الأدوية المسجلة أو المتداولة في مصر.
  • حداثة كل سعر أو توافر المنتج في الصيدليات.
  • صحة الاستخدامات أو بيانات العبوة لكل سجل دون مراجعة مصدرية مستقلة.
  • أن ظهور المنتج في الفهرس يثبت تسجيله الحالي لدى الهيئة.

تنبيه: استخدم نتائج البحث للتعرّف الأولي فقط. لا تعتمد عليها لتحديد جرعة أو بدء علاج أو استبدال دواء. راجع النشرة المعتمدة والطبيب أو الصيدلي.
