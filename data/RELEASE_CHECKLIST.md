# مراجعة ما قبل الإطلاق

## اختبارات ثابتة
- [x] الصفحات الأساسية موجودة وتستخدم العربية واتجاه RTL.
- [x] فحص صياغة JavaScript المضمن في الصفحات.
- [x] التحقق من صحة ملفات JSON الأساسية.
- [x] التأكد من أن دليل الصيدليات لا يعرض إلا السجلات الموثقة.
- [x] إضافة فحص آلي يمكن تشغيله بالأمر `node tests/smoke-check.js`.

## اختبارات تشغيلية مطلوبة قبل الإطلاق
- [ ] فتح الصفحات على هاتف Android وشاشة كبيرة.
- [ ] اختبار خدمة بحث الأدوية الخارجية فعليًا، بما في ذلك الترقيم والتفاصيل ومعدل الإتاحة.
- [ ] اختبار OCR بصور عبوات عربية وإنجليزية متنوعة، والتحقق من أن المستخدم يراجع النص المستخرج قبل البحث.
- [ ] اختبار عدم وجود أخطاء شبكة أو JavaScript في المتصفح.
- [ ] مراجعة طبية وصيدلانية مستقلة لمحتوى الأعراض والإسعافات والنصائح والمكتبة.
- [ ] مراجعة شروط ترخيص البيانات ومصدر كل حقل، ومراجعة سياسة الخصوصية.
- [ ] إدخال بيانات أدوية وصيدليات فقط بعد التحقق من المصادر والمراجعة.

## بوابة النشر
لا يتم النشر العام قبل اجتياز الاختبارات التشغيلية ومراجعة المحتوى والبيانات. لم يُنفذ النشر ضمن هذه المرحلة.
