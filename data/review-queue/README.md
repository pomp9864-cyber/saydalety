# قائمة المراجعة

توضع هنا السجلات المرشحة قبل اعتمادها. لا تُقرأ ملفات هذا المجلد من واجهة البحث العامة.

## حالات العمل
- `pending`: واردة ولم تراجع.
- `needs_source`: تحتاج مصدرًا أو إثباتًا.
- `clinical_review`: تحتاج مراجعة صيدلانية للمحتوى الطبي.
- `approved`: اجتازت المراجعة ويمكن نقلها إلى الكتالوج.
- `rejected`: مرفوضة مع توثيق السبب.

كل سجل مرشح يجب أن يحمل مصدره وتاريخ جمعه، وألا يحتوي على بيانات شخصية غير لازمة.
