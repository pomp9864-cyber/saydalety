# سجل الأدوية

هذا المجلد هو مصدر بيانات الأدوية المنظم للمشروع. لا تُضاف أي مادة دوائية إلى نتائج البحث العامة إلا بعد استيفاء متطلبات التوثيق والمراجعة.

## الملفات
- `catalog.json`: فهرس المنتجات المقبولة للنشر.
- كل منتج له معرّف ثابت وسجل مستقل عند الحاجة.
- `status` يميز بين المسودة والمراجعة والاعتماد.

## قواعد أساسية
1. لا تُنشأ أسماء أو أسعار أو أرقام تسجيل بالتخمين.
2. يُسجل الاسم التجاري والمادة الفعالة والتركيز والشكل الصيدلي والعبوة كحقول منفصلة.
3. السعر بالجنيه المصري مع تاريخ التحقق ومصدره.
4. لا تُنشر الجرعات أو الاستطبابات أو التحذيرات إلا بمصدر موثوق ومراجعة صيدلانية.
5. البديل المطابق في المادة والتركيز والشكل يختلف عن البديل العلاجي؛ يجب توضيح النوع.
6. لا تعني خلو الفهرس من السجلات أن السوق المصري خالٍ من الأدوية؛ بل يعني أن سجلات لم تجتز المراجعة بعد.
