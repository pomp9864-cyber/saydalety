# المساهمة في بيانات صيدليتي

## دورة اعتماد أي سجل
1. **جمع:** تحديد مصدر يمكن الرجوع إليه، مع تاريخ الوصول.
2. **تطبيع:** توحيد كتابة الأسماء والتركيزات والوحدات والأشكال الصيدلية دون فقد بيانات العبوة.
3. **تحقق:** مطابقة هوية المنتج أو الصيدلية مع مصدر موثوق مستقل قدر الإمكان.
4. **مراجعة:** مراجعة بشرية للحقول الطبية، ومراجعة منفصلة للأسعار والبيانات التشغيلية.
5. **نشر:** لا ينتقل السجل إلى الكتالوج العام إلا بعد اكتمال التحقق.

## الحد الأدنى لسجل الدواء
- اسم تجاري، مادة فعالة، تركيز، شكل صيدلي، شركة/مصنّع عند توفره.
- مصدر لكل معلومة أساسية، وتاريخ تحقق.
- السعر اختياري؛ إذا أضيف فيجب توثيق مصدره وتاريخ سريانه.
- الحالة الافتراضية `pending`، ولا تظهر السجلات المعلقة للجمهور.

## الحد الأدنى لسجل الصيدلية
- اسم، محافظة، عنوان قابل للتحقق، مصدر، تاريخ آخر تحقق.
- لا تُنشر أرقام هواتف أو مواقع جغرافية إلا إذا كانت منشورة بمصدر مشروع وتم التحقق منها.
- بيانات الصيدليات تتغير؛ يلزم إعادة التحقق دوريًا.

## ممنوع
- توليد سجلات وهمية أو تخمين الأسعار أو أرقام التسجيل.
- نسخ قواعد بيانات دون مراجعة شروط الترخيص وإعادة الاستخدام.
- تقديم بيانات الدليل باعتبارها تشخيصًا أو وصفة طبية.
